# 0000 — Modello per le decisioni

Copiare questo file per ogni nuova decisione, numerandolo progressivamente.

## Stato
Proposta / Accettata / Superata da 00XX

## Data
AAAA-MM-GG

## Contesto
Qual era il problema e quali vincoli c'erano.

## Decisione
Cosa si è deciso, in una frase.

## Alternative considerate
Cosa si è scartato e perché.

## Conseguenze
Cosa diventa più facile e cosa più difficile. Cosa sarà costoso cambiare.
